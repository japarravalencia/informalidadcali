> **Parra Valencia, J. A., Marín, B., Pabón, S., & Mossos, N. (2026).** *Escaping the Indicator Trap: A Multi-Methodology Viable System Model (VSM) and System Dynamics Assessment of Reactive Welfare, Labor Informality, Adjusted Multidimensional Poverty (MPI_Adjusted), and Employment Quality Index (ICE) in Cali, Colombia (2010–2040).*

## Launch the Interactive Simulator
Open directly in any desktop or mobile browser (no installation required):
- **Web Flight Simulator (GitHub Pages):** https://TU-USUARIO.github.io/cali-indicator-trap-simulator/
- **Stella WebAssembly Simulator (isee Exchange):** https://exchange.iseesystems.com/public/jorgeandrick/informalidad-reactiva-pobreza-monetaria-e-ipm
- **Permanent XMILE Archive (.stmx & Data):** https://doi.org/10.5281/zenodo.22962097

## Key Features
- Continuous-time ODE System Dynamics engine (Euler, `dt = 0.25 yr`) with explicit `DELAY3`, `SMTH1`, and `SMTH3` delays.
- All 7 published scenarios (Runs 249–255), including Baseline, Punitive Audits, Youth Fiscal Rule, MPI Optimal, MPI Pragmatic, and Extreme Conditions 1 & 2.
- Interactive Viable System Model (VSM) & Canonical Feedback Loop Explorer (`B1`, `B2`, `B3`, `R1`, `R2`).
- Live Loops That Matter (LTM) dominance chart, empirical DANE/DAPM calibration overlays (2010–2026), and one-click CSV data export.
